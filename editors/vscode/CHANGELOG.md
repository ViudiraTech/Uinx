# Changelog

## 0.3.0

- Initial VS Code extension for Uinx 0.3.
- TextMate grammar, language configuration, snippets.
- `uinx-lsp` client with `uinxc` fallback diagnostics.
- Commands for check/build/run/test/fmt/lint/new project/show IR.
- `uinx` task provider with `$uinx` problem matcher.
- Extension icon: navy `U` with indent steps and amber entry dot.
